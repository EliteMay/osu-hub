## 実装

### Dashboard

Homeを改善ループの入口へ変更した。

- 最新同期状態
- 保存Results件数 / Average Accuracy
- Active Practice
- 最近の変化
- 難易度 / Sessionの重要傾向
- 最近のResults / Practice
- Sync / Results / Analysis / Practice / Coachingへの導線

保存済みLocal Data表示は外部API応答を待たない。

### Navigation

Primary NavigationをCurrent Requirementへ合わせた。

```text
Dashboard
Results
Analysis
Practice
Coaching

Tools
Settings
```

`Account Sync` はPrimary Navigationから外し、DashboardやSettings等から入るSecondary Surfaceとした。

### Results

- 譜面名 / Artist / MOD / メモ検索
- Recent / Best / API / Manual Filter
- Star Rating範囲Filter
- 日付 / Accuracy / Miss / PP / Star Rating Sort
- 50件単位のLoad More
- Result詳細Dialog
- 手動メモ編集
- Beatmap Link
- 手動Result追加

既存 `osu:<score id>` ID Contract、API再同期時の重複防止、手動メモ保持を変更していない。

### Analysis

ResultsからOn-demandで次の4系統を計算する。

1. 成長推移
2. 難易度別
3. 安定性
4. Session比較

初期Session境界は、45分以上プレイ間隔が空いた場合を別SessionとするBest Reasonable Defaultとした。

Data不足時は断定せずInsufficient Data Stateを表示する。

難易度分析からPracticeフォームへContextを引き継げる。

### Practice

旧Todo形式から改善サイクルへ拡張した。

Lifecycle:

```text
planned
↓
active
↓
completed
```

保持する主な情報:

- Theme
- 苦手 / 原因
- Goal
- Action
- Start Date / Duration
- 関連Analysis
- Before Snapshot
- After Snapshot
- Review

新規Practice作成時に開始日前までの直近ResultsをBeforeとして保存し、完了時に開始日以降のResultsからAfterを作成する。

### Coaching → Practice

既存のChatGPT提出ZIP / AI JSON Validationを維持したまま、AIの `recommendedPractice` をPracticeへつなぐBridgeを追加した。

重要:

- AI提案を自動的にPracticeへ保存しない
- `Practiceで確認` からフォームへ引き継ぐ
- Userが内容を確認してSubmitした場合のみ正式Practiceとして保存する

有料OpenAI APIは必須にしていない。

## Storage / Migration

IndexedDB `osuHubDB` をDB / Schema Version 2へ更新した。

```text
results
sessions
coaching
practice
settings
```

### Compatibility

- Schema v1 BackupをImport可能
- v1 Import時は `sessions: []` を補完
- 旧Practice Recordをv2 Lifecycleへnormalize
- 旧PracticeがDB内に残っている場合もBackup Export時にv2正規形へnormalize
- Future Schemaは拒否
- Unknown Storeは書込前に拒否
- Import前に全Record Validation
- Recovery Snapshotを作成
- Transaction write後にread-back Verification
- Failure時Rollbackを維持

既存Dataをclearしてから不正Importに気付く処理にはしていない。
