# 作業報告書 - Setup Launcher初回GitHub Release

## 目的

GitHub Releasesが空でDesktop Toolsからinstallerを取得できない状態を解消し、`osu Setup Launcher v0.17.0` のSetup.exeをGitHub Releasesへ初回配布する。

`web-project-guide` Guide Version `1.3.0` のElectron / 配布ルールを確認し、Setup.exe生成を実Windowsランナーで確認してからReleaseを公開する手順にした。

Project Profile:

```text
STATIC + DATA + AI-HANDOFF + CLOUD + ELECTRON + TOOL
```

## 変更内容

### Windows Build / Release Workflow

`.github/workflows/build-windows.yml` を更新。

- Desktop関連のmain変更時にWindows buildを実行
- Node.js 20 + `npm install`
- `npm run build:win`
- `dist/osu_setup_<version>_setup.exe` の存在確認
- 1MB未満の異常に小さいinstallerを失敗扱い
- Actions Artifactへ保存
- `package.json#version` から `v<version>` tag / Releaseを決定
- GitHub Releaseを作成または更新
- Setup.exeをRelease assetとしてupload
- コード署名なし / Windows実機動作未確認をRelease Notesへ明記

Releaseはbuildとinstaller検証が成功した場合のみ作成される。
